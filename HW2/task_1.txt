\section{Overview}
This document summarizes the implementation details, mathematics, experimental setup and comparative results for three tabular reinforcement learning algorithms applied to the CliffWalking environment: SARSA (on-policy TD), Q-Learning (off-policy TD), and Dyna-Q (model-based planning with Q-Learning updates). The implementations are provided in \texttt{agent.py} and corresponding training scripts \texttt{cliff\_walk\_sarsa.py}, \texttt{cliff\_walk\_qlearning.py}, \texttt{cliff\_walk\_dyna\_q.py}. A unified evaluation script is in \texttt{evaluate\_cliffwalk.py} to produce learning curves and final paths.

\section{Environment and Notation}
We use OpenAI Gym's \texttt{CliffWalking-v0} (4x12 grid) with discrete states $s\in\{0,\dots,47\}$ and actions $a\in\{0,1,2,3\}$. Each step returns reward $r$ (typically $-1$ for non-terminal steps, large negative for cliff). $\gamma$ denotes the discount factor, $\alpha$ the learning rate, and $\epsilon$ the exploration parameter for an $\epsilon$-greedy policy.

\section{Common Implementation Details}
To keep implementations consistent:
\begin{itemize}
  \item Q-values stored as a lazy-initialized table: \texttt{defaultdict(lambda: np.zeros(|A|, dtype=np.float32))}. This avoids predefining state count and creates a new zero vector for unseen states.
  \item Action selection uses $\epsilon$-greedy with deterministic argmax (\texttt{np.argmax}) for exploitation. Formally, the policy is
  \[
    \pi_{\epsilon}(a\mid s) = \begin{cases}
      1 - \epsilon + \dfrac{\epsilon}{|\mathcal{A}|}, & a = \operatorname*{argmax}\limits_{a'} Q(s,a')\\[4pt]
      \dfrac{\epsilon}{|\mathcal{A}|}, & \text{otherwise}
    \end{cases}
  \]
  \item Epsilon decay is multiplicative and applied at the end of each episode in our training loops: $\epsilon_{k+1}=\max(\epsilon_{\min},\lambda\,\epsilon_k)$ with $\lambda\in(0,1)$ (we use $\lambda=0.995$ and $\epsilon_{\min}=0.1$ by default).
\end{itemize}

\section{SARSA (On-policy TD)}
\subsection{Update rule}
On-policy TD(0) with target using the next action $a'$ sampled from current policy:
\begin{align}
\delta_t &= r_t + \gamma\, Q(s_{t+1}, a_{t+1}) - Q(s_t,a_t),\\
Q(s_t,a_t) &\leftarrow Q(s_t,a_t) + \alpha\,\delta_t.
\end{align}
If $\text{done}=\text{True}$, we do not bootstrap ($Q(\text{terminal},\cdot)=0$), hence
\(\ \delta_t = r_t - Q(s_t,a_t)\).

\subsection{Pseudo-code}
\begin{enumerate}
  \item Initialize $Q(s,a)=0$; set $\alpha,\gamma,\epsilon,\epsilon_{\min},\lambda$.
  \item For each episode:
  \begin{enumerate}
    \item Reset $s$; select $a$ using epsilon-greedy (take $\operatorname*{argmax}_{a} Q(s,a)$ with probability $1-\epsilon$, otherwise pick a random action uniformly).
    \item Loop until termination: execute $a$ to obtain $(s', r, \text{done})$;
    \begin{itemize}
      \item If done: $\delta=r-Q(s,a)$; update $Q(s,a)\leftarrow Q(s,a)+\alpha\,\delta$; terminate.
      \item Otherwise: select $a'$ using epsilon-greedy on $Q(s',\cdot)$ (same rule as above), compute $\delta=r+\gamma\,Q(s',a')-Q(s,a)$ and update; set $s\leftarrow s'$, $a\leftarrow a'$.
    \end{itemize}
    \item Decay $\epsilon\leftarrow\max(\epsilon_{\min},\lambda\,\epsilon)$.
  \end{enumerate}
\end{enumerate}

\section{Q-Learning (Off-policy TD)}
\subsection{Update rule}
Off-policy TD(0) with greedy target:
\begin{align}
\delta_t &= r_t + \gamma\, \max_{a'} Q(s_{t+1}, a') - Q(s_t,a_t),\\
Q(s_t,a_t) &\leftarrow Q(s_t,a_t) + \alpha\,\delta_t.
\end{align}
If $\text{done}=\text{True}$, then $\delta_t = r_t - Q(s_t,a_t)$.

\subsection{Pseudo-code}
\begin{enumerate}
  \item Initialize $Q$ and hyperparameters.
  \item For each episode: reset $s$ and loop until termination:
  \begin{enumerate}
  \item Choose $a$ using epsilon-greedy (take $\operatorname*{argmax}_{a} Q(s,a)$ with probability $1-\epsilon$, otherwise random) and interact to obtain $(s', r, \text{done})$.
    \item Compute $\delta=r+\gamma\max_{a'}Q(s',a')-Q(s,a)$ (if done, the target is $r$).
    \item Update $Q(s,a)$, set $s\leftarrow s'$, and decay $\epsilon$.
  \end{enumerate}
\end{enumerate}

\section{Dyna-Q (Model-based Planning)}
\subsection{Update rule and planning}
After each real interaction, perform two types of updates:
\begin{enumerate}
  \item \textbf{Real update} (same as Q-Learning):
  \(\ \delta=r+\gamma\max_{a'}Q(s',a')-Q(s,a)\ \) (if done, the target is $r$).
  \item \textbf{Model learning and planning}: record a model $\mathcal{M}(s,a)=(\hat s,\hat r,\hat d)$; repeat $n_{\text{plan}}$ times, sample a previously seen $(\tilde s,\tilde a)$, query $(\tilde s',\tilde r,\tilde d)=\mathcal{M}(\tilde s,\tilde a)$ and perform a ``virtual'' Q-learning update (terminal samples also do not bootstrap).
\end{enumerate}

\subsection{Pseudo-code}
\begin{enumerate}
  \item Initialize $Q$ and an empty model $\mathcal{M}$; set $n_{\text{plan}}$.
  \item For each episode: run real interactions and update $Q$; then perform $n_{\text{plan}}$ model-based updates.
\end{enumerate}

\subsection{Implementation notes}
\begin{itemize}
  \item The implementation uses a simple deterministic model mapping $(s,a)\to(s',r)$ and stores \texttt{done} as well to handle terminal transitions consistently during planning.
  \item Default planning steps used in experiments: $n_{plan}=20$ (configurable).
\end{itemize}

\section{Experimental Setup}
\begin{itemize}
  \item Environment: \texttt{CliffWalking-v0} (4x12 grid).
  \item Training: each agent is trained for $N$ episodes (the evaluation script defaults to $N=1000$); maximum steps per episode: 500. All three algorithms use the same hyperparameters for a fair comparison:
  \begin{itemize}
    \item \texttt{SarsaAgent(action\_space, alpha=0.1, gamma=0.99, epsilon=1.0, epsilon\_min=0.1, epsilon\_decay=0.995)}
    \item \texttt{QLearningAgent(A, alpha=0.1, gamma=0.99, epsilon=1.0, epsilon\_min=0.1, epsilon\_decay=0.995)}
    \item \texttt{Dyna\_QAgent(A, alpha=0.1, gamma=0.99, epsilon=1.0, epsilon\_min=0.1, epsilon\_decay=0.995, n\_planning=20)}
  \end{itemize}
  \item Seed: fixed random seed for reproducibility in examples (e.g. 0).
  \item Metrics recorded per episode: cumulative episode reward, current $\epsilon$.
  \item Evaluation: after training, set $\epsilon=0$ to roll out a greedy path for visualization.
\end{itemize}

\subsection{Result analysis and expected observations}
\begin{itemize}
  \item \textbf{Path difference (SARSA vs Q-Learning)}: In most runs, \textbf{SARSA learns a more conservative path} that stays farther from the cliff, while \textbf{Q-Learning tends to hug the cliff} and find the shortest (optimal) path.
  \begin{itemize}
    \item \textit{Reason}: SARSA is on-policy and its target uses the next action value under the current $\epsilon$-greedy policy, $r+\gamma Q(s',a')$. With nonzero $\epsilon$, $a'$ carries the risk of exploratory moves that may fall into the cliff; this risk is reflected in the target and pushes the policy to prefer safer routes.
    \item By contrast, Q-Learning is off-policy and bootstraps with a greedy target $r+\gamma\max_{a'}Q(s',a')$, ignoring the exploration risk in the next step. This biases learning toward the maximal-value (shortest) path along the cliff edge.
  \end{itemize}
  \item \textbf{Model-based (Dyna-Q) vs model-free (SARSA/QL) efficiency}: \textbf{Dyna-Q typically learns faster} (steeper reward improvements and earlier convergence) than SARSA or Q-Learning given the same interaction budget.
  \begin{itemize}
    \item \textit{Reason}: After each real step, Dyna-Q performs $n_{\text{plan}}$ model-based updates, effectively multiplying value propagation and improving sample efficiency. In the deterministic CliffWalking environment, the learned one-step model is accurate, so these planning updates are especially effective.
    \item With identical hyperparameters and per-episode $\epsilon$ decay, the speedup observed in reward curves primarily stems from planning rather than differences in exploration schedules.
  \end{itemize}
  \item \textbf{What you should see in plots}: path visualizations usually show the \textit{SARSA path staying farther from the cliff}, while \textit{Q-Learning and Dyna-Q paths closely follow the cliff}. Reward curves typically show \textit{Dyna-Q rising earlier and stabilizing faster} than the two model-free baselines.
\end{itemize}

\section{Conclusions}
\begin{itemize}
  \item Implementations for SARSA, Q-Learning and Dyna-Q follow standard textbook formulae and share a consistent epsilon-greedy action selection mechanism with decay.
  \item Dyna-Q offers improved sample efficiency at the cost of additional CPU updates (planning).
  \item The difference between SARSA and Q-Learning arises from on-policy vs off-policy targets and typically reflects in path conservativeness near the cliff.
\end{itemize}
